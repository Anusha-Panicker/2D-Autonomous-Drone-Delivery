1.1  Problem Formulation — 20 marks

x, f(x), and all constraints are precisely defined in standard form; the problem is realistically scoped (not trivial, not unsolvably complex); units/context are sensible for the chosen domain. 

1.2  Convexity / KKT Analysis — 25 marks 

Hessian correctly computed; PSD/definiteness check correctly executed and interpreted; convexity conclusion is correct. If constrained: Lagrangian correctly formed, KKT conditions correctly checked, active/inactive constraints correctly identified with justification. 

1.3  Implementation & Convergence Comparison — 25 marks 

Both Gradient Descent and Heavy-Ball correctly implemented and produce sensible results; convergence plots are clear and correctly labeled; comparison explicitly references condition number κ and correctly explains the speed difference (or correctly explains why there is little difference). 

1.4  Reflection & Insight — 15 marks 

Specific, thoughtful reflection that connects numerical results back to course theory (convexity, κ, momentum); proposes a concrete, plausible extension. 

1.5  Viva — 15 marks 

Explains their own formulation, analysis, and code fluently without prompting; correctly explains any AIassisted parts in their own words; handles follow-up “what if” questions confidently.
